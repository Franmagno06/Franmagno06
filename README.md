Stack

Linguagens: TypeScript, JavaScript, Java, GDScript

Backend: Node.js, Express, Prisma ORM, Zod, autenticação JWT/bcrypt, arquitetura em camadas (Routes → Controller/Service → Repository)

Frontend: Next.js, React, Vite, Tailwind CSS, React Router, TanStack Query

Banco de dados: PostgreSQL (Supabase, Neon e Docker local)

IA aplicada: Google Gemini (análise de documentos, extração de PDF, saída estruturada via JSON Schema)

Testes e qualidade: Vitest, Supertest, Playwright, CI com GitHub Actions

Outros: Docker, Godot Engine (GDScript), deploy em Vercel/Render/Neon

Projetos em Destaque
PortfolioLab: plataforma web de gestão de carteira de investimentos (ações, FIIs, ETFs e renda fixa), com simulação de rebalanceamento de aportes, importação automática de proventos e análise de relatórios financeiros por IA (upload de PDF com resumo executivo e chat sobre o documento). Backend em Node.js/TypeScript/Express/Prisma/PostgreSQL, frontend em Next.js, com mais de 200 testes automatizados.
Desafio-Vortex: também conhecido como Circula, um marketplace/PWA de economia circular do campus, onde estudantes doam, vendem e trocam livros, jalecos e materiais universitários. Desenvolvido como desafio técnico do processo seletivo de estágio full-stack do Laboratório de Inovação Vortex (Unifor) e já em produção (frontend na Vercel, API na Render, banco na Neon).
Rancho-do-Saber: jogo educativo feito em Godot (GDScript), inspirado no visual de Stardew Valley, voltado a crianças do ensino fundamental para ensinar Português e Matemática através da exploração de uma fazenda interativa.
Calculadora-Logica: calculadora de lógica proposicional feita em JavaScript, que interpreta expressões com operadores lógicos (negação, conjunção, disjunção, ou-exclusivo, condicional e bicondicional) e gera automaticamente a tabela-verdade correspondente.
Calculadora-de-Aportes-de-Investimentos: ferramenta em Java, orientada a objetos, para automatizar o cálculo de rebalanceamento de aportes mensais em uma carteira de investimentos (ações, FIIs e renda fixa), distribuindo o valor investido de acordo com os pesos-alvo definidos para cada classe de ativo.
